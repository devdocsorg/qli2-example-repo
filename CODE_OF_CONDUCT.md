# Code of Conduct

Treat participants with respect, welcome different experiences, and keep feedback
focused on the work. Harassment, threats, discriminatory remarks, and sharing
someone's private information without permission are unacceptable.

Participation follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
including its standards and
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
This applies to this repository, its issues and pull requests, and spaces where
participants represent the project.

## Report a concern

Email [info@devdocs.work](mailto:info@devdocs.work),
[DevDocs' published contact](https://devdocs.work/terms#contact), with the subject
"qli2-example-repo conduct concern". This reaches the organisation maintaining the
repository without posting the report in the issue tracker.

Describe what happened, include relevant links where available, and state how you
would like to be contacted. Share only the personal information needed to explain
the concern. If the report involves a maintainer, identify that conflict when
requesting review. This example does not promise a response deadline.
