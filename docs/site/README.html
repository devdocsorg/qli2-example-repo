QLI 2.0 repository skeleton documentation¶

Start with the adoption tutorial, or follow development environment setup to improve the skeleton.

Folders¶

  • user/ — Explains adoption and the skeleton’s configuration.

  • contributing/ — Owns contribution guidance and development setup.

  • .templates/ — Supplies the generated site’s entry-point redirect.

Files¶

  • Makefile: Provides the shared local and CI setup, build, and reproducibility commands.

  • README.md — Introduces the guides and supplies the site’s homepage.

  • conf.py — Configures Markdown rendering, local navigation, and search.

  • requirements.txt — Pins the documentation packages.

  • requirements.lock — Locks direct and transitive documentation dependencies for reproducible builds.
