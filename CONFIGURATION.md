# Configuration

## Runtime

The CLI has one optional setting, documented beside its safe value in
[.env.example](.env.example):

| Variable | Purpose and type | Optional/default | Safe example |
| --- | --- | --- | --- |
| `SUMMARY_FORMAT` | Select the report format: `text` or `json` | Optional; `text` when unset; empty or other values fail | `text` |

The process reads environment variables. To load a file, use Node's built-in
`--env-file` option as shown in the [tutorial](docs/tutorials/summarize-a-build-log.md).
Existing environment variables take precedence. File paths are relative to the
working directory. The program has no credentials, network access, or other settings.

## package.json

[package.json](package.json) is JSON; the table documents its settings in place of
inline comments. Scripts run from the repository root. Keep these explicit values
when reproducing the example; omitted entry points or scripts will not provide the
documented commands. Package metadata is descriptive, while `private: true` is the
publication guard (npm otherwise allows publication).

| Key | Purpose and type | Value/default in this example |
| --- | --- | --- |
| `name` | String; package and CLI identity | `qli-buildlog-summary` |
| `version` | String; development package version | `1.0.1`; this does not create a release tag |
| `private` | Boolean; prevent accidental npm publication | `true` |
| `description` | String; package summary | Describes this example's scope |
| `license` | String; SPDX identifier | `BSD-3-Clause`, matching LICENSE |
| `bin.qli-buildlog-summary` | String; executable entry when installed locally | `dist/src/cli.js`; requires a build |
| `main` | String; CommonJS library entry | `dist/src/index.js` |
| `types` | String; generated TypeScript declarations | `dist/src/index.d.ts` |
| `scripts.build` | String; compile source and tests | `tsc` |
| `scripts.demo` | String; build and summarize the committed sample | `npm run build --silent && node dist/src/cli.js examples/sample-build.log` |
| `scripts.test` | String; compile and run the built tests | `tsc` followed by Node's test runner |
| `scripts.docs` | String; regenerate API documentation | `typedoc` |
| `scripts.check` | String; complete local validation | Tests, reference generation, and `scripts/check-docs.mjs` |
| `engines.node` | String; supported Node version range | `>=22` |
| `devDependencies.@types/node` | Version string; API types for the minimum Node major | `^22.20.2`; development only |
| `devDependencies.typescript` | Version string; compiler | `^5.9.0`; development only |
| `devDependencies.typedoc` | Version string; reference generator | `^0.28.0`; development only |
| `devDependencies.typedoc-plugin-markdown` | Version string; Markdown output for TypeDoc | `^4.9.0`; development only |

[package-lock.json](package-lock.json) is generated by npm, including transitive
versions, integrity hashes, and registry locations. Use `npm ci` to reproduce it;
update it with npm when changing dependencies. There are no runtime dependencies.

## tsconfig.json

All listed options are explicitly set in [tsconfig.json](tsconfig.json). Other
options use the pinned compiler's defaults.

| Key | Purpose and type | Value/default in this example |
| --- | --- | --- |
| `compilerOptions.target` | String; emitted JavaScript language level | `ES2022` |
| `compilerOptions.module` | String; module output format | `commonjs` |
| `compilerOptions.moduleResolution` | String; import-resolution strategy | `node` |
| `compilerOptions.rootDir` | Path string; common source root | `.` so tests and source keep their folders |
| `compilerOptions.outDir` | Path string; generated files | `dist`, ignored by Git |
| `compilerOptions.declaration` | Boolean; emit library type declarations | `true` |
| `compilerOptions.newLine` | String; generated line endings | `lf` for consistent output |
| `compilerOptions.esModuleInterop` | Boolean; CommonJS/ES-module import compatibility | `true` |
| `compilerOptions.strict` | Boolean; strict type checks | `true` |
| `compilerOptions.noUncheckedIndexedAccess` | Boolean; expose potentially missing indexed values | `true` |
| `compilerOptions.skipLibCheck` | Boolean; skip rechecking dependency declarations | `true`; project source remains checked |
| `include` | Array of directory paths to compile | `src` and `test` |

## typedoc.json

[typedoc.json](typedoc.json) generates a single browsable Markdown API file.

| Key | Purpose and type | Value/default in this example |
| --- | --- | --- |
| `$schema` | URL string; editor validation for this configuration | `https://typedoc.org/schema.json` |
| `entryPoints` | Array of source paths; public API to document | `src/index.ts` |
| `out` | Directory path; reference destination | `docs/reference` |
| `cleanOutputDir` | Boolean; whether to erase the output directory | `false` to preserve the handwritten README |
| `readme` | Path string or `none`; extra project prose | `none`; the handwritten reference README is the entry page |
| `gitRevision` | String; revision in generated source links | `main` |
| `plugin` | Array of plugin names | `typedoc-plugin-markdown` |
| `outputFileStrategy` | String; page grouping | `modules`; the single public entry produces one file |
| `entryFileName` | Filename string; generated entry page | `API.md` |
| `hidePageHeader` | Boolean; omit redundant page navigation | `true` |
| `treatWarningsAsErrors` | Boolean; fail on documentation warnings | `true` |

Only [API.md](docs/reference/API.md) is generated. Keep the
[reference README](docs/reference/README.md) handwritten. CI detects uncommitted
reference changes after generation.

## Repository configuration

[.gitignore](.gitignore), [CODEOWNERS](.github/CODEOWNERS), and the
[CI workflow](.github/workflows/check.yml) document their rules inline.
[Bug](.github/ISSUE_TEMPLATE/bug_report.md) and
[feature](.github/ISSUE_TEMPLATE/feature_request.md) templates use GitHub's front
matter: `name` and `about` label the chooser; empty `title`, `labels`, and `assignees`
leave those decisions to the reporter and maintainers. The
[pull request template](.github/PULL_REQUEST_TEMPLATE/pr_template.md) is selected
through the `template=pr_template.md` parameter in the contribution link.
