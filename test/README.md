# Index

## Description

Automated tests use the built-in Node.js test runner. `npm test` compiles the
project and runs every `*.test.js` file in the compiled output.

## Files

- [README.md](README.md) — Describes this folder and lists its files.
- [cli.test.ts](cli.test.ts) — Exercises argument handling, configuration, errors, JSON, and the tutorial output in real CLI processes.
- [`summarizer.test.ts`](summarizer.test.ts) — Covers log parsing, summary aggregation, and both output formats.
